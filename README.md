# Latihan Inheritance - Pemrograman Berorientasi Objek

Repository ini berisi tugas mata kuliah Pemrograman Berorientasi Objek mengenai materi Inheritance (Pewarisan).

## Penjelasan Konsep
Inheritance adalah konsep dalam Pemrograman Berorientasi Objek di mana sebuah class (subclass) dapat mewarisi atribut dan method dari class lain (superclass). Hal ini memungkinkan penggunaan kembali kode secara efisien tanpa harus menulis ulang dari awal.
